# Public portfolio audio

This source snapshot uses CC0 recordings by Mafon2.
- Cat Meow: https://freesound.org/people/Mafon2/sounds/436541/
- Cat short purr: https://freesound.org/people/Mafon2/sounds/436542/
- CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/

miina_meow.wav / miina_purr.wav use Cat Meow. In this PUBLIC SOURCE SNAPSHOT,
miina_affection.wav and miina_sad.wav also use that same Cat Meow recording.
miina_stroke_purr.wav uses Cat short purr, with the processing described below.
The two site-specific Taira Komori recordings used in the private application
are not distributed in this snapshot. The sound selection differs from that app.

Cat Meow was converted to 16-bit PCM, retaining 44,100 Hz stereo and 25,226 frames.
Cat short purr was converted to 16-bit PCM, retaining 44,100 Hz stereo and 58,323 frames,
with 80 Hz high-pass, EQ, compression and limiting as documented in the private source baseline.

Build verification for this public snapshot is run by the included Android CI.
Physical-device testing is separate and has not been performed for this snapshot.
